## 4. 影响评估

1. 若不先收敛，项目将出现“执行按 A 文档、验收按 B 文档”的治理失效。
2. 依赖倒挂会导致风险控制任务名义完成但实际不可执行。
3. 指标口径漂移会使 S2 接管率验收存在统计争议，直接影响 GO/NO-GO。
4. SQL 方言错位会在安全落地时失败，形成“纸面合规”。
